
# Ceylonora - Luxury Coastal Villa Booking System

## About the Project
Ceylonora is a web-based villa and room booking system developed to provide an easy and convenient way for guests to explore rooms and make reservations.

## Main Features
- View available rooms
- Room booking
- Guest registration and login
- Booking management
- Admin dashboard

## Technologies Used
- HTML
- CSS
- JavaScript
- PHP
- MySQL
- WampServer

## Installation
1. Install WampServer.
2. Copy the project folder into the www directory.
3. Start Apache and MySQL.
4. Create a database named coastal_villa.
5. Import the project database tables.
6. Open the project in your browser.

## Project URL
http://localhost/CoastalVilla/
